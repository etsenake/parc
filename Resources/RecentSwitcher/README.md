# Recent-item switcher illustrations

`Bundle.image(forResource:)` and `NSPDFImageRep.pdfRepresentation` exported
160 × 120 point PDFs:

- `NotePreviewThumbnail.pdf`: fallback artwork for Notes.
- `EaselPreviewThumbnail.pdf`: fallback artwork for Easels.
- `IncognitoTabPreviewThumbnail.pdf`: fallback artwork for private web pages
  without an available page snapshot.

Notes and Easels pair their illustration with the document title. The excluded
shared-service item has no Parc producer or copied artwork. Packaging copies
this directory with the other application resources.

See [tab switcher](../../docs/tab-switcher.md#cards-and-thumbnails)
for card behavior and ownership.
