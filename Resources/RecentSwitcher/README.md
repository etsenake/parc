# Recent-item switcher illustrations

These template illustrations are Parc's own 160 × 120-point vector PDFs, drawn
as filled shapes with a few fixed opacities so the system tint shows through:

- `NotePreviewThumbnail.pdf`: fallback artwork for Notes, two paragraphs of
  rounded word bars at 10% opacity.
- `EaselPreviewThumbnail.pdf`: fallback artwork for Easels, a scattered
  pattern of circles, squares, triangles, plus signs, waves and dots at four
  opacities.
- `IncognitoTabPreviewThumbnail.pdf`: fallback artwork for private web pages
  without an available page snapshot, a slashed eye at 25% opacity.

Notes and Easels pair their illustration with the document title. Packaging
copies this directory with the other application resources.

See [tab switcher](../../docs/tab-switcher.md#cards-and-thumbnails)
for card behavior and ownership.
