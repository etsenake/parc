# Site Control Center artwork

Parc's Site Control Center template images:

- `icon-control-center`: toolbar and address-pill entry glyph, a rounded square
  with two sliders, 18 × 18 points.
- `copy-url`: Copy URL button, the Feather link drawing (MIT, credited on the
  licences page), 19 × 19 points.
- `capture-full-page`: full-page capture button, corner brackets around lines
  of text, 19 × 19 points.

Each name has a vector `.pdf` plus `.png` and `@2x.png` renditions rendered from
the same geometry with 8× supersampling.

`SiteControlCenterArtwork` combines both bitmaps and the vector at the 1× size
as a template. Share and Capture use the SF Symbols `square.and.arrow.up` and
`camera`. Visible Area uses the full-strength `photo.artframe` symbol.

See [web interactions](../../docs/web-interactions.md) for Site Control Center
behavior.
