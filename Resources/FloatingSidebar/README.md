# Floating sidebar artwork


- The image is a black ring: a 10-point ramp up to 0.37 alpha around a clear, 10-point-radius hole the size of the stretched centre.
- The 1× and 2× PNGs are the catalog's compiled renditions as AppKit returns them for the named image, written by ImageIO without resizing, keeping the Generic Gray Gamma 2.2 profile and alpha.
