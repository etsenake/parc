# Scripting component checks

Run `bash scripts/test-scripting.sh` from the repository; the main suite in `scripts/test.sh` runs it too. The harness compiles the scripting interface with the shared browser-state sources and packages the executable with the production dictionary as its main bundle, so Cocoa actually registers the scripting classes and unique-ID container specifiers. It constructs a bare NSApplication with a fake delegate and fake browser owners; it does not run the application event loop or create browser windows.

The checks cover Cocoa application getter/factory/collection-setter delegation, the post-factory insertion shape and one-use acknowledgment before native readiness, tab/Space creation, identity/profile invalidation, same-owner navigation dispatch, URL validation, and synchronous/asynchronous close completion. A real browser state with archived tabs, a profile being removed and repeated tab identities checks that the window's tab-selection rules, which use the tab index, give the same lists, order and single-tab matches, in the window and inside each Space, as filtering every tab and taking the first match.

They also build the object references AppleScript compiles for `properties of every tab`, `properties of active tab` and `tell space "Work" to focus`, and run them through Cocoa's registered get and focus commands in-process. That shows the replies are records under the dictionary's codes and that a Space is found by its title. The fake window counts its full tab listings and single-tab lookups, so the checks also prove that `properties of every tab`, `title of every tab` and `every tab of space` list the tabs once and then need one lookup per tab, that `id of every tab` needs only the listing, that a tab named by its id, in the window or inside a Space, or the active tab is found without listing the window or Space, and that the records, order and later changes come through unchanged. In this in-process harness, a failed lookup makes every later lookup in the same run fail too, so the unknown-title check runs last.

No Apple Event is sent or dispatched, and no `osascript`, browser engine, personal profile or user's clipboard is used. Further automation remains explicitly deferred in [local scripting](../../docs/scripting.md).
